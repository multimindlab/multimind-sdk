# 🧠 MultiMind SDK — LLM Integration Metadata

**MultiMind SDK** is an open-source, model-agnostic framework for developing, fine-tuning, and routing both **Transformer** and **Non-Transformer** LLMs.

Unlike LangChain or LlamaIndex, MultiMind SDK supports universal orchestration and training of models like:
- 🤖 Transformers (BERT, GPT, Mistral, Qwen, etc.)
- 🧬 Non-Transformers (Mamba, RWKV, Hyena, SSMs, RNNs)

## 🚀 Key Capabilities
- RAG (Retriever-Augmented Generation)
- Agent Orchestration & Evaluation
- Transformer + Non-Transformer Model Wrappers
- Fine-tuning & Adapter Support (QLoRA, PEFT)
- Model Routing, Evaluation, CLI + UI integrations
